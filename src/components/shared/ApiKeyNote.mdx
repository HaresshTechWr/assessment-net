<Admonition type="warning" title="API Key Security">

**Never** expose your API key in client-side code, browser requests, or public repositories. Store it as an environment variable and rotate it from the [Netomi Dashboard](https://app.netomi.com) under **Settings → API Keys** if it is ever compromised.

</Admonition>
