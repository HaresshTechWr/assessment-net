# Introduction

Welcome to the **Netomi API documentation**. Netomi provides an agentic AI platform that helps enterprises automate customer experience at scale.

This documentation is intended for **developers** integrating Netomi into their applications or workflows.

## What you can do with the Netomi API

- Automate customer conversations using AI agents
- Integrate Netomi into your existing CRM or support tools
- Trigger agent workflows via webhooks
- Monitor and manage agent performance programmatically

## Who this is for

This documentation is for developers who want to:

- Build integrations using the Netomi REST API
- Use the Netomi SDK in their applications
- Set up webhook listeners for real-time event handling

### Before you begin

You will need:

- A Netomi account with API access enabled
- An API key (see [Authentication](./02-getting-started/authentication.md))
- Basic familiarity with REST APIs
